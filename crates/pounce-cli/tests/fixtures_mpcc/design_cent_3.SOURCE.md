# `design_cent_3.nl`

`design-cent-3` from MacMPEC (S. Leyffer), the `.nl` as distributed in
`MacMPEC-nl.tar.gz` (2009), unchanged. Best known objective 3.7237
(maximize). 15 variables, 11 rows, 3 complementarity pairs, each on a row
with 8 Jacobian entries.

It is here because its paired rows are exactly as wide as
`complementarity_lift=auto`'s threshold (`LIFT_AUTO_MIN_ENTRIES`), so it is
the fixture that reaches the lifted path at the default.

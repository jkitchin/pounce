* Formulation
#+begin_example
  min  q(x) = 1/2 (x0^2 + x1^2)
  s.t. x0 + x1 = 1          (equality)
       x0 - x1 >= 0.5       (inequality)
#+end_example
P = I (SPD), q = 0. On the equality line, the unconstrained min of 1/2||x||^2 is
(0.5, 0.5), which gives x0 - x1 = 0 < 0.5 and violates the inequality; hence the
inequality binds. Solving x0 + x1 = 1 and x0 - x1 = 0.5 gives x* = (0.75, 0.25),
q* = 1/2(0.5625 + 0.0625) = 0.3125.

KKT verification: grad q = (0.75, 0.25); a_eq = (1,1), a_ineq = (1,-1).
(0.75, 0.25) = mu(1,1) + lam(1,-1) => mu = 0.5, lam = 0.25 >= 0, so the
inequality multiplier is non-negative: x* is the unique strictly-convex minimizer.

* D5 — near-degenerate (LICQ-borderline) active constraints  [PASS, expected degradation]
:PROPERTIES:
:FAMILY: diff
:REPORT: [[file:runs/2026-07-23_diff_near_degenerate_licq.py]]

Two nearly-parallel active normals [1,0],[1,eps]; sweep eps. Analytic dL/dh
tracks FD as long as the active KKT matrix is reasonably conditioned:
| eps  | cond(KKT) | grad err vs FD |
| 1e-1 | 1.1e3     | 3.0e-8         |
| 1e-3 | 1.1e7     | 4.6e-7         |
| 1e-5 | 1.1e11    | 4.0e-4         |
| 1e-7 | 1.1e15    | 2.3e-1         |
Error scales ~cond*eps_machine — textbook conditioning-limited accuracy. At
eps=1e-7 the active KKT system is numerically singular (LICQ fails), so dx*/dh
is genuinely ill-defined and BOTH the analytic gradient and the cvxpy FD are
unreliable. Graceful degradation, not a gradient bug. Consistent with the
already-noted sensitivity-family degenerate behavior (not filed).

* Verdict
No findings. The differentiable-layer stack (QP + SOCP, jax + torch) is correct
across first-order, second-order, multi-active, cone-boundary, and batched
regimes. The only accuracy loss is at genuine LICQ breakdown, which is expected
and shared by the finite-difference oracle. Two non-correctness notes recorded
(jax P=None ergonomics; the P-gradient symmetric convention).

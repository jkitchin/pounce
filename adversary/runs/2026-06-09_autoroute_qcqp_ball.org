#+TITLE: Autoroute transparency — convex QCQP (linear obj over a ball) -> socp
#+DATE: 2026-06-09

* Problem properties
- Family ............ autoroute (pounce.minimize, default solver_selection="auto")
- Class ............. convex QCQP — linear objective + one convex quadratic
  (Euclidean-ball) inequality constraint. The quadratic *constraint* is what
  routes this to the conic (SOCP) path rather than the LP/QP path.
- SOURCE ............ classic "minimize a linear functional over a Euclidean
  ball": closed-form optimum, also re-verified with cvxpy.
- Expected route .... socp (convex QCQP reformulated to SOCP, pounce.solve_socp).
- KNOWN_OPTIMAL ..... -9.0  at x* = -R c/||c|| = (-1, 2, -2)
  (R=3, c=[1,-2,2], ||c||=3, obj* = -R||c|| = -9).

* Formulation
  minimize    c.x,                 c = [1, -2, 2]
  subject to  x0^2 + x1^2 + x2^2 <= R^2,   R = 3
  no bounds, no other constraints.  x0 = (0,0,0) (strictly interior).
  scipy-style ineq: g(x) = R^2 - x.x >= 0,  jac = -2x.

#+TITLE: Adversary: differentiable SOCP layer (norm-ball constrained QP)
#+DATE: 2026-06-09

* Problem properties
- SOURCE: Euclidean projection onto a ball, posed as a second-order-cone
  program; canonical SOCP differentiable-layer example (cf. cvxpylayers /
  Agrawal et al., "Differentiable Convex Optimization Layers", NeurIPS
  2019; conic OptNet).
- Layer type: =pounce.jax.solve_socp= / =pounce.torch.solve_socp=
  (cone-aware OptNet implicit differentiation; arrow-operator path).
- Dims: n=3 variables; one second-order cone of dim n+1=4; no equalities.
- Distinct from box QP and from the equality QP above: a genuine conic
  (second-order-cone) constraint that is ACTIVE at the optimum, so the
  cone arrow-operator gradient path is exercised, not a polyhedral KKT.

* Formulation
#+begin_example
  min   1/2 ||x||^2 + c^T x
  s.t.  || x - center || <= r          (one SOC, dim 4)
#+end_example
Standard form  min 1/2 x^T P x + c^T x  s.t. Gx <=_K h, with P=I and slack
s = h - G x in SOC(4):
  s0  = r            -> G row 0 = 0,  h0 = r
  s1: = center - x   -> G rows  = I,  h1: = center
Differentiable w.r.t. (c, h); h carries the radius r and the center.
Loss for gradient tests: L = w . x*. Reference = cvxpy/CLARABEL re-solve.

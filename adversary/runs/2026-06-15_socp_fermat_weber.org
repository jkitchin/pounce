** Problem
Single-facility Fermat-Weber (geometric median, unit weights):
   minimize   sum_i ||x - p_i||_2
over the facility location x in R^2. Closed form via an EQUILATERAL triangle:
all interior angles are 60 deg < 120 deg, so the Fermat point is the centroid,
which sees each pair of vertices at 120 deg, and f* = s*sqrt(3) for side s.

We use an equilateral triangle of side s = 1 centered at the origin:
  p0 = (0, 1/sqrt(3)), p1 = (-1/2, -1/(2 sqrt(3))), p2 = (1/2, -1/(2 sqrt(3))).
(circumradius 1/sqrt(3); all three side lengths asserted = 1.0.) The Fermat
point is (0,0) and f* = sqrt(3) = 1.7320508076.

** Cone encoding (the trap)
pounce: s = h - G x in the listed cones; soc dim d => s0 >= ||s_{1:}||_2.
Epigraph: minimize sum t_i with each ||x - p_i|| <= t_i as one dim-3 soc cone:
  s0 = t_i        -> G row -1 in col (2+i),  h  0
  s1 = x1 - p_ix  -> G row -1 in col 0,      h -p_ix
  s2 = x2 - p_iy  -> G row -1 in col 1,      h -p_iy
=> t_i >= ||x - p_i||_2. Verified per-row sign, column, and dim before running.
Independent epigraph-tightness check: true f(x_pounce) == sum t_i to 4.5e-9.

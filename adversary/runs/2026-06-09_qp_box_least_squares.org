#+TITLE: Adversary QP cross-check: box-constrained least squares (separable diagonal QP)
#+DATE: 2026-06-09

* Problem properties
- FAMILY: qp (convex QP via interior-point method)
- CLASS: box-constrained least squares / separable diagonal QP
- SOURCE: Closed-form KKT (derivable). A separable diagonal QP decouples
  coordinate-wise; the optimum is the projection of the unconstrained
  minimizer onto each box: x_i* = clamp(t_i, lb_i, ub_i).
- KNOWN_OPTIMAL: analytic, x* = clip(t, lb, ub); obj* = 0.5 * sum w_i (x_i*-t_i)^2
  (seed=7 -> obj* = 6.6514113181e+01)
- N_VARIABLES: 50
- N_CONSTRAINTS: 100 box bounds (50 lb + 50 ub); no equalities, no general inequalities
- Active set at optimum: 10 at lb, 16 at ub, 24 interior (nontrivial)

* Formulation
  min  0.5 * sum_i w_i (x_i - t_i)^2   s.t.  -2 <= x_i <= 2
Data: w_i ~ U(0.5,3.0) (so P = diag(w) is PD), t_i ~ U(-5,5) (seed=7).

pounce form (minimize 0.5 x'Px + c'x):
  P = diag(w),  c = -w*t,   lb = -2,  ub = 2.
pounce.obj omits the constant CONST = 0.5*sum w_i t_i^2; added back in script.

P is PD: min eigenvalue = 5.622e-01 > 0.
Sign/cone convention: bounds passed via lb/ub kwargs; matches cvxpy xv>=lb, xv<=ub.

Aimed at the homotopy's `delta` regularization: the path is traced on `H + delta*I` with delta a 1e-6 *relative* perturbation, and on a spectrum spanning 1e8 a relative perturbation is not obviously harmless -- too large and it mispredicts the active set. It does not: the active-set path matches the oracle to 4.2e-9, slightly closer than the IPM, at half the wall time. The two oracles agree only to 3.2e-6 with each other, which bounds how much can be concluded below that level.

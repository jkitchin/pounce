#+TITLE: Adversary Run: Lagrange Multiplier Correctness on HS21 / HS43 / HS53 / HS73
#+DATE: <2026-07-22>

* Problem
:PROPERTIES:
:FAMILY: nlp
:CLASS: duals / multipliers / sensitivity invariants
:SOURCE: W. Hock & K. Schittkowski, "Test Examples for Nonlinear Programming Codes", LNEMS 187, Springer 1981 — problems 21, 43 (Rosen-Suzuki), 53, 73 (cattle feed)
:KNOWN_OPTIMAL: HS21 -99.96 | HS43 -44 | HS53 176/43 = 4.0930232558 | HS73 29.894378
:N_VARIABLES: 2 / 4 / 5 / 4
:N_CONSTRAINTS: HS21 1 ineq + 2 bounds | HS43 3 nonlinear ineq | HS53 3 linear eq + bounds | HS73 2 ineq (1 nonlinear) + 1 eq + lower bounds
:END:

Four problems were chosen to span every multiplier kind, and none appears in
=adversary/log.org= (which already holds HS1, 13, 14, 15, 28, 35, 71, 76, 100,
110).

** HS21 — active BOUND, inactive inequality
\[
\min\ 0.01x_1^2 + x_2^2 - 100 \quad \text{s.t.}\quad 10x_1 - x_2 \ge 10,\;
2 \le x_1 \le 50,\; -50 \le x_2 \le 50
\]
\(x^\*=(2,0)\), \(f^\*=-99.96\). The inequality is slack (20 ≥ 10); the only
active constraint is the lower bound on \(x_1\), so analytically
\(z_{L,1}=\partial f/\partial x_1 = 0.02x_1 = 0.04\), \(\lambda = 0\).

** HS43 (Rosen–Suzuki) — three nonlinear inequalities, two active
\[
\min\ x_1^2+x_2^2+2x_3^2+x_4^2-5x_1-5x_2-21x_3+7x_4
\]
subject to three \(c_i(x)\ge 0\) rows. At \(x^\*=(0,1,2,-1)\), \(f^\*=-44\),
rows 1 and 3 are active and row 2 is slack. Solving
\(\nabla f = \mu_1\nabla c_1 + \mu_3\nabla c_3\) by hand gives
\(\mu=(1,0,2)\) exactly — the published H&S multipliers.

** HS53 — three linear EQUALITIES, bounds inactive
\[
\min (x_1-x_2)^2+(x_2+x_3-2)^2+(x_4-1)^2+(x_5-1)^2
\]
s.t. \(x_1+3x_2=0\), \(x_3+x_4-2x_5=0\), \(x_2-x_5=0\), \(-10\le x\le 10\);
\(f^\*=176/43\). Pure equality case — the multipliers are free-sign, so this is
the row type most likely to expose a non-uniform sign bug.

** HS73 (cattle feed) — equality + inequality + ACTIVE bound, all at once
Linear objective, one linear inequality, one *nonlinear* (square-root)
inequality, one linear equality, and \(x\ge 0\) with \(x_2\) active at its lower
bound. \(f^\*=29.894378\). This is the single problem that exercises all four
multiplier kinds simultaneously.

* Method

Script: [[file:2026-07-22_duals_hs_multipliers.py]] (< 3 s total).

All derivatives (gradient, Jacobian, Hessian of the Lagrangian) are generated
symbolically with sympy from a *single* expression source that is also fed to
Pyomo, so the pounce model and the Ipopt model are provably the same model. A
central finite-difference check of the gradient and Jacobian runs at the
solution of every problem (max error 3.7e-9) to rule out the #1 false positive.

Duals are read from the *native* =Problem.solve= contract
(=info["mult_g"]=, =info["mult_x_L"]=, =info["mult_x_U"]=), which
=docs/src/differentiable-solves.md= documents as **cyipopt-compatible**, i.e.

\[
\mathcal{L} = f + \lambda^{\mathsf T} g - z_L^{\mathsf T}(x-x_L) + z_U^{\mathsf T}(x-x_U)
\]

Solves use =nlp_scaling_method=none=, =tol=1e-10=.

Lagrangian are \(\partial f^\*/\partial b = -\lambda\) for general-constraint

** (e) Bound multipliers for ACTIVE bounds

Two genuinely active bounds appear: HS21 \(x_1 = 2\) and HS73 \(x_2 = 0\).
Both are recovered with the correct nonnegative sign, matched to the analytic
value (9.8e-12, 1.9e-10) and — independently — to the finite-difference
\(\partial f^\*/\partial x_L\) at ratio +1. Inactive bounds report exactly zero.

Magnitudes are identical to ≤ 1.5e-10. The sign difference is a **uniform
global negation**: −1 on every row, on equality and inequality rows alike, on
all four problems, with no row-type-dependent behaviour. This is the already
known =.sol=-writer dual-negation issue reported separately today; it is
*not* counted as a new finding here. Concretely, the =.sol= path emits the
internal cyipopt-convention =mult_g= verbatim without applying the AMPL sign
flip that Ipopt's own =.sol= writer applies — which is exactly the shape of a
single uniform negation.

* Cross-check / Verification

- Derivative FD check at every solution: grad err ≤ 3.7e-9, Jacobian err ≤ 1.3e-9.
- Analytic multipliers recomputed *without pounce*, by least-squares solution of
  the active-set stationarity system, and separately by hand for HS43.
- Published H&S optima reproduced to ≤ 4.9e-9 relative.
- Ipopt 3.x via Pyomo on a model built from the same expression source.
- Finite-difference \(df^\*/db\) with full re-solves — no convention assumed.

* Verdict

*PASS.* Across an active bound (HS21), pure nonlinear inequalities (HS43), pure
equalities (HS53), and a mixed equality + inequality + active-bound problem
(HS73), pounce's =Problem= API multipliers satisfy the KKT stationarity identity
to machine precision in the sign convention it documents, match published and
independently derived analytic values to ≤ 2e-10, and match the convention-free
finite-difference \(df^\*/db\) at ratio exactly ±1 as the documented Lagrangian
requires. Active-bound multipliers are correct in both magnitude and sign, and
inactive rows are exactly zero. Versus Ipopt the magnitudes agree to ≤ 1.5e-10
and the only discrepancy is a *uniform* negation on the Pyomo/=.sol= path —
identical across equality and inequality rows, hence the already-known
=.sol=-writer issue and not a new or non-uniform defect.

* Problem
:PROPERTIES:
:FAMILY: power
:CLASS: p-norm epigraph (p=3) with equality budget + inactive box lower bound
:SOURCE: convexity of t^3 on t>=0 + symmetric Lagrange stationarity (elementary)
:KNOWN_OPTIMAL: 111.111111... (=3000/27)
:N_VARIABLES: 6 (3 x_i, 3 epigraph t_i)
:N_CONSTRAINTS: 3 pow cones (alpha=1/3, dim 3 each) + 3 nonneg rows + 1 equality
:SELECTED_BY: log-rotation
:COVERAGE_TARGET: - (coverage-combined.sh skipped per sandbox env adaptations; family-coverage table used instead, power tied least-tested at 10)
:END:

Minimize $\sum x_i^3$ s.t. $\sum x_i = 10$, $x_i \ge 1$. Symmetric
Lagrange stationarity ($3x_i^2=\lambda\ \forall i$, unconstrained by the
bound) forces $x_i=10/3$ for all $i$, which satisfies $10/3>1$ so the box
is provably inactive. Known optimum $3(10/3)^3=3000/27\approx111.1111$.
Encoded via pow-cone epigraph $(x_i,t_i,1)\in K_{pow}(\alpha=1/3)$
($|x_i|\le t_i^{1/3}\Leftrightarrow x_i^3\le t_i$ for $x_i\ge0$), plus an
explicit nonneg-cone row for the (inactive) bound $x_i\ge1$ and an
equality block for the budget.

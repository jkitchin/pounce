* Problem
:PROPERTIES:
:FAMILY: qp
:CLASS: equality+box convex QP (closed-form via water-filling)
:SOURCE: Boyd & Vandenberghe, "Convex Optimization" (2004) Sec 5.5.3-style KKT argument; Duchi, Shalev-Shwartz, Singer, Chandra, "Efficient Projections onto the l1-Ball" (ICML 2008) Sec 3, for the box-simplex generalization
:KNOWN_OPTIMAL: 9.125 (computed by closed-form bisection, not a fixed literature constant)
:N_VARIABLES: 5
:N_CONSTRAINTS: 1 equality + 10 box bounds
:SELECTED_BY: log-rotation
:COVERAGE_TARGET: -
:END:

\[
\min_x \; \tfrac{1}{2}\|x-a\|_2^2 \quad \text{s.t.} \quad \mathbf{1}^\top x = s,\;\; 0 \le x \le 3
\]

with \(a = (1, 4, -2, 6, 0.5)\), \(s=5\). For a fixed equality multiplier
\(\nu\), \(x_i(\nu) = \mathrm{clip}(a_i-\nu, 0, 3)\) is monotone decreasing,
so bisecting \(g(\nu)=\sum_i x_i(\nu) - s = 0\) gives the exact KKT point
independent of any QP solver ("water-filling").

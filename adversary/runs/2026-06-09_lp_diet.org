* Problem properties
- FAMILY: lp
- CLASS: bounded LP with >= (floor) inequality constraints, unique vertex optimum
- SOURCE: Classic diet/blending LP (Dantzig diet problem, textbook 3-food/2-nutrient variant). Optimum derivable in closed form and confirmed by two oracles.
- KNOWN_OPTIMAL: min cost = 66/7 = 9.4285714286 at x* = (15/7, 0, 24/7)
- N_VARIABLES: 3 (food amounts, x >= 0)
- N_CONSTRAINTS: 2 nutrient floors (>=) + 3 lower bounds

* Formulation
minimize  c.x,  c = [2, 3, 1.5]
subject to N x >= r,
  N = [[4,2,1],[1,3,2]], r = [12, 9]
  x >= 0

pounce convention is G x <= h, so the >= floors are encoded as G = -N, h = -r.
Active set at optimum: both nutrient floors and x1 = 0 (vertex with food 1 unused).

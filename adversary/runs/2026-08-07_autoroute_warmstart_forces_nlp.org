$f(x)=0.5x_1^2+0.5x_2^2-x_1-2x_2$ s.t. $x_1,x_2\ge0$, $x_1+x_2\le5$
(inactive). Unconstrained stationary point $(1,2)$ is feasible, so
$x^*=(1,2)$, $f^*=-2.5$.

Two calls: (r1) ~solver_selection="auto"~, no warm_start -- expected to
route to the convex QP solver (~info["solver"]~ set). (r2) same options
plus a ~WarmStart~ captured from r1 -- per the docstring and the code path
cited above, this must *force* the NLP path (warn, and ~info["solver"]~
must NOT show a convex-solver tag), not silently honor "auto" and use the
convex solver while ignoring (or mis-seeding) the warm start.

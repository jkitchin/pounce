#+TITLE: Batch adversary (a) — solve_qp_multi_rhs, shared SPD P, 12 unconstrained objectives
#+DATE: 2026-06-09

* Problem properties
- FAMILY: batch (solve_qp_multi_rhs)
- SOURCE: synthetic; one fixed SPD P (n=6) swept against 12 distinct cost vectors c_i.
  RNG seed 20260609 (numpy default_rng). P = M Mᵀ + nI symmetrized → SPD, well-conditioned.
- BATCH SIZE: 12 items, each n=6, UNCONSTRAINED (no A/b/G/h/lb/ub).
- KNOWN_OPTIMAL: unconstrained convex QP ⇒ x*_i = -P⁻¹ c_i (closed form, exact).
- PER-ITEM DIMS: n=6 variables, 0 constraints.

* Formulation
For each i:  min_x  ½ xᵀ P x + c_iᵀ x.
Stationarity: P x + c_i = 0 ⇒ x*_i = -P⁻¹ c_i. P shared across the batch; only c_i varies,
which is exactly the multi-RHS use case (cs = [c_0 … c_11]).

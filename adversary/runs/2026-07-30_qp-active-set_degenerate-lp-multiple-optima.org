Separately it drives BOTH Python surfaces -- `solve_qp(method='active-set')` and `minimize(solver_selection='qp-active-set')` -- which this PR unified after they had silently named two different algorithms. They agree with each other and the oracle, and `nfev == 0` confirms the convex driver ran rather than an NLP fallback.

1. `QpLayer.batch(cs)` matches a Python loop over `QpLayer(c_i)` bit-exactly
   (0.0 max abs diff) — the rayon batch driver produces identical primal
   solutions to independent single solves.
2. `jax.grad` through `loss_batch` (one call through the batch driver)
   matches the sum of independent `jax.grad` calls through the single-item
   `__call__` (a materially different Rust code path) to 0.0 max abs diff.
3. Central finite difference (\(\epsilon=10^{-6}\), float64) on two batch
   items (6 scalar perturbations total) matches the batched analytic
   gradient to 8.93e-10, well under the 5e-5 FD tolerance.
4. `pounce.jax.QpLayer.batch` and `pounce.torch.QpLayer.batch` agree
   forward (0.0) and on the backward gradient (1.11e-16, float64 machine
   epsilon) — full JAX<->Torch parity on this entry point.

* Verdict
PASS — `QpLayer.batch()`'s implicit-differentiation gradient is correct
against three independent checks (per-item loop, finite difference, and

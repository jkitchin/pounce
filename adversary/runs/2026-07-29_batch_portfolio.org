* Problem
:PROPERTIES:
:FAMILY: batch
:CLASS: solve_qp_batch vs per-item solve_qp + closed-form KKT
:SOURCE: classic Markowitz mean-variance QP, diagonal covariance, single budget
  equality constraint (no bounds); closed-form KKT derived in the script header.
:KNOWN_OPTIMAL: analytic per-instance (see script; 8 instances, random seed 20260729)
:N_VARIABLES: 6 per instance x 8 instances
:N_CONSTRAINTS: 1 equality per instance (budget sum(x)=1)
:SELECTED_BY: log-rotation
:COVERAGE_TARGET: - (coverage-combined.sh skipped per environment adaptation; batch was the least-tested family in adversary/log.org's Family-coverage table, Tested=5, lowest of all 13)
:END:

For each instance $k$: minimize $\tfrac12 x^\top D_k x - \mu_k^\top x$ s.t.
$\mathbf{1}^\top x = 1$, with $D_k = \mathrm{diag}(d_k)$, $d_k \sim U(0.5,20)$,
$\mu_k \sim U(-3,3)$, $n=6$. KKT gives $x_i^* = (\mu_i+\lambda)/d_i$ with
$\lambda = (1-\sum_i \mu_i/d_i)/\sum_i 1/d_i$.

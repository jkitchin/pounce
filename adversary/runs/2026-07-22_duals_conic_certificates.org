** pounce standard form and the identities under test

#+begin_src text
min  1/2 x'P x + c'x   s.t.  A x = b,   s = h - G x  in  K
#+end_src

Stationarity, as pounce itself computes it (=qp.rs::kkt_residuals_inner=):
=P x + c + A'y + G'z = 0=.  So the Lagrangian is
=L = 1/2 x'Px + c'x + y'(Ax-b) + z'(Gx-h)=, the dual objective is
=d(y,z) = -1/2 x'Px - b'y - h'z= with =z in K^*=, and

#+begin_src text
p* - d* = <s, z>          (duality gap IS the complementarity product)
#+end_src

Checks per case: (a) dual cone membership, (b) zero duality gap,
(c) per-block complementary slackness, (d) stationarity, (e) cvxpy cross-check
of primal AND dual.

** The dual cones (the crux)

=soc=, =psd=, =nonneg= are self-dual.  =exp= and =pow= are *not*.  Derived from
=K^* = { z : <z,s> >= 0 for all s in K }= (the sign convention forced by the
Lagrangian above), then checked against MOSEK:

With pounce's =K_exp = cl{(a,b,c) : b>0, b e^{a/b} <= c}=, minimizing
=u a + v b + w c= over the cone forces =w >= 0=, sets =c = b e^{a/b}=, and by
positive homogeneity reduces to =g(a) = u a + v + w e^a >= 0=.  For =w>0= the
minimizer is =a* = ln(-u/w)= (needs =u<0=), giving =v + p - p ln(p/w) >= 0= with
=p = -u=, i.e.

#+begin_src text
K_exp^* = cl{ (u,v,w) : u < 0,  w >= -u * e^{-1} * exp(v/u) }
          u  { (0,v,w) : v >= 0, w >= 0 }
#+end_src

MOSEK writes the primal as ={x : x1 >= x2 exp(x3/x2), x2>0}= and the dual as
={u : u1 >= -u3 e^{-1} exp(u2/u3), u3 < 0}=.  Under the mapping
MOSEK =(x1,x2,x3) = pounce (c,b,a)= (hence =(u1,u2,u3) = (w,v,u)=) that is
character-for-character the same set.  *Agreement confirmed.*

With pounce's =K_pow(al) = {(a,b,c) : |a| <= b^al c^(1-al), b,c >= 0}=, the worst
case is =a = -sign(u) b^al c^(1-al)=; =v,w >= 0= follows from letting =b,c -> inf=
at =a=0=; and the weighted-AM-GM minimum of =v b + w c= on =b^al c^(1-al) = 1= is
=(v/al)^al (w/(1-al))^(1-al)=.  Hence

#+begin_src text
K_pow(al)^* = { (u,v,w) : |u| <= (v/al)^al (w/(1-al))^(1-al),  v,w >= 0 }
#+end_src

matching MOSEK Sec. 4.1.2 under =(x1,x2,x3) = pounce (b,c,a)=.  *Confirmed.*

** Self-test of my own derivation (run BEFORE grading pounce)

The script refuses to grade pounce unless its dual-cone formulas pass:

1. 60 000 sampled points of =K_exp= (and of =K_pow=) all have
   =<z,s> >= 0= against 2 000 sampled points of the claimed =K^*=
   (observed minima =+2.03e-04= and =+1.80e-04=, i.e. never negative).
2. Every point pushed *just outside* the claimed =K^*= is *refuted* by an
   analytically constructed =s in K= (=s* = (ln(-u/w), 1, -u/w)= for exp;
   =s* = (-sign(u) b^al c^(1-al), al/v, (1-al)/w)= for pow) —
   *100 % refutation rate* for both cones.  (Random sampling of =K= alone only
   refuted 97.6 % of exp cases; the miss was my sampling range, not the formula.
   Using the exact minimizer closes it.)
3. Two hand-computed complementary pairs land exactly on both boundaries with
   =<s,z> = 0= to machine precision:
   - exp: =s = (0,1,1)=, =z = (-1,-1,1)=  -> both violations =0=, =<s,z> = 0=
   - pow(1/3): =s = (4,1,8)=, =z = (-1,4/3,1/3)= -> violations =0/2.2e-16=,
     =<s,z> = -4.4e-16=

** (a) Dual cone membership — including the non-self-dual discriminator

Every returned =z= is in the correct dual cone with violation *exactly 0.0*,
including both exponential blocks and the power block.

Critically, the test is *sensitive to the distinction*: the returned exp dual
=(-1.00008, -1.0, 1.0)= violates the *primal* =K_exp= by =1.00e+00=, and the
returned pow dual =(-1.0, 1.3334, 0.3333)= violates the *primal* =K_pow(1/3)= by
=4.71e-01=.  A naive self-dual check would have (wrongly) flagged both as bugs.
So pounce is returning genuine =K^*= members, not =K= members, and this run
actually exercises the distinction rather than passing vacuously.

** (b)/(c) Gap and complementarity

The identity =p* - d* = <s,z>= holds exactly in every case (both columns above
agree to the last printed digit), which is itself a consistency check on my
reading of pounce's Lagrangian sign convention.  Relative gaps 3e-12 … 2e-09.

** (d) Stationarity

=||c + A'y + G'z||_inf= is 7.6e-10 or smaller everywhere, confirming both the
identity documented in =qp.rs= and the sign of =y= and =z=.

* Verdict

*PASS.*  All five requested certificate properties hold for all four cone types.
The load-bearing result is (a): the exponential and power cones are not
self-dual, I re-derived =K_exp^*= and =K_pow(al)^*= from first principles and
confirmed both against the MOSEK Modeling Cookbook and against hand-computed
complementary pairs before touching pounce, and the duals pounce returns lie in
those dual cones with violation exactly zero — while lying *outside* the
corresponding primal cones by O(1), which proves the check discriminates rather
than passing vacuously.  Zero duality gap, per-block complementary slackness,
and the documented stationarity identity =c + A'y + G'z = 0= all hold to 1e-9 or
better, and cvxpy/CLARABEL agrees on primal and dual for every case, with
pounce's duals more accurate than the oracle's on three of the four.  The only
blemishes are cosmetic: =optimal_inaccurate= status and ~1e-4 dual-value error
on the exp/pow HSDE path at tight tolerances, which the oracle shares and which
pounce reports honestly.  No bug found.

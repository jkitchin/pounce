\[
\min_x \ \tfrac12 x^\top \Sigma x - \gamma \mu^\top x \quad
\text{s.t.} \ \mathbf{1}^\top x = 1,\ x \ge 0
\]

$\Sigma,\mu$ constructed (seed 3) so the equality-only KKT optimum is
strictly interior (every $x_i>0$), so the no-short bound never binds and
the closed-form solution $x^* = \gamma\,\Sigma^{-1}\mu - \lambda\,\Sigma^{-1}\mathbf 1$
(with $\lambda$ fixing $\mathbf 1^\top x^*=1$) is exact.

This run does not re-adjudicate the formulation (already PASS since
2026-06-09, rel err 6.5e-12). Instead it sweeps two option axes on the
*same* data and data, per adversary.md's "attack the option space" arm:

1. =tol= over 1e-4 .. 1e-12 (6 values), default =method="ipm"=.
2. =method="ipm"= vs =method="active-set"= (the two QP engines pounce
   ships through =solve_qp=), same problem.

* Formulation
#+begin_example
  min  q(x) = 1/2 (x0^2 + x1^2) - x0 - 4 x1
  s.t. 0 <= x0 <= 2
       0 <= x1 <= 2
#+end_example
P = I (symmetric positive definite), q = (-1, -4). The unconstrained minimizer is
x = -P^{-1} q = (1, 4). Clipping to the box leaves x0 = 1 interior and binds the
upper bound x1 = 2, so x* = (1, 2) and q* = 1/2(1 + 4) - 1 - 8 = -6.5. Sign
convention: pounce / pyomo minimize; bounds are simple variable bounds in the .nl.

* How the active-set path was invoked
The Python =minimize= facade does NOT expose =solver_selection="qp-active-set"=;
it is reachable only via the CLI. The QP is emitted as an AMPL =.nl= (pyomo) and run:
#+begin_example
  pounce model.nl out.sol solver_selection=qp-active-set --json-output out.json
#+end_example
=crates/pounce-cli/src/dispatch.rs= maps ="qp-active-set"= ->
=SolverChoice::QpActiveSet= (validating the class is LP / convex QP), and
=crates/pounce-cli/src/main.rs= then sets =algorithm active-set-sqp=, routing the
solve through the active-set SQP engine (its step QPs solved by =pounce-qp=) -- a
DISTINCT code path from the IPM. IPM cross-check: =solver_selection=qp-ipm=.

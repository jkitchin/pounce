* Problem properties
- NAME: Six-hump camel function (unconstrained polynomial global minimization)
- SOURCE: Molga & Smutnicki, "Test functions for optimization needs" (2005);
  Dixon-Szegő standard global-optimization test set.
- OBJECTIVE:
  f(x,y) = (4 − 2.1 x² + x⁴/3) x² + x y + (−4 + 4 y²) y²

- RELAXATION ORDER tested: 0, 1, 2 (order = extra Lasserre levels above the
  degree-induced minimum of 3).
- Coercive (x⁶, y⁴ leading) ⇒ bounded below ⇒ unconstrained SOS valid.

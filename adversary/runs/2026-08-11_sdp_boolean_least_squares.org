True (NP-hard) problem: $\min_{x\in\{-1,1\}^n} \|Ax-b\|_2^2$, $A\in\mathbb
R^{5\times4}$, $b\in\mathbb R^5$ (seed 11). Homogenize $y=(1,x)$,
$Y=yy^\top$ (rank-1 PSD, $\mathrm{diag}(Y)=1$):
\[
\|Ax-b\|_2^2 = \mathrm{trace}(QY), \qquad
Q = \begin{pmatrix} b^\top b & -(A^\top b)^\top \\ -(A^\top b) & A^\top A \end{pmatrix}.
\]
SDP relaxation (drop the rank-1 constraint):
\[
\min_Y\ \mathrm{trace}(QY) \quad\text{s.t.}\quad \mathrm{diag}(Y)=1,\ Y\succeq 0.
\]
This is a genuine mathematical *lower bound* on the true combinatorial
minimum for any Y feasible in the relaxation -- so pounce's returned
"optimal" value must satisfy
$\text{pounce\_obj} \le \text{true\_combinatorial\_min} + \text{tol}$.
A violation (pounce returning a value strictly above what is actually
achievable) would indicate an invalid solve, not merely a loose bound.

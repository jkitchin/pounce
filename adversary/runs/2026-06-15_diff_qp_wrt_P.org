#+TITLE: Adversary report — Differentiable QP layer w.r.t. the matrix P (diff/gradient)
#+DATE: 2026-06-15

* Summary
- *Problem*: inequality-constrained convex QP differentiated w.r.t. the
  QUADRATIC COST MATRIX =P= (theta = P). This is the one differentiable
  parameter not yet covered by the diff family — prior runs differentiated
  w.r.t. =c=, =h=, =A=, =b=, and SOCP cone data. The 2026-06-09 eqcon run
  explicitly *skipped* FD on P (deferring to gradcheck) due to the symmetry
  projection; this run does it correctly.
- *Layer type*: =pounce.jax.solve_qp= / =pounce.torch.solve_qp= OptNet/IFT
  differentiable QP layer, x*(P).
- *N_VARIABLES*: n = 3 (P is 3x3 symmetric), 4 inequality constraints, exactly
  ONE active.
- *VERDICT*: PASS.

* Formulation
#+begin_src
min  1/2 x^T P x + c^T x
s.t. G x <= h        (4 rows; row 0 active, slack ~0.7-1.1 on the rest)
loss = w . x*(P)
#+end_src
P SPD (M M^T + 0.5 I), well conditioned. Active set stable under the small
symmetric perturbations FD/gradcheck apply → no kink crossing.

* The symmetry subtlety (why this test exists)
P enters only through the quadratic form 0.5 x^T P x, so only its symmetric
part is identifiable. Both backends return a *symmetrized* gradient dL/dP. A
naive entrywise central FD that bumps P[i,j] alone double-counts off-diagonal
contributions. The correct oracle is therefore

    sym(FD) = 0.5 (FD_entrywise + FD_entrywise^T).

This run reports BOTH:
- analytic vs sym(FD):     1.16e-10   ← the real check (PASS)
- analytic vs entry(FD):   1.41e-01   ← expected mismatch, demonstrates the
                                        symmetric convention is in play.
gradcheck routes P through a symmetric parametrization P = S + S^T so the
perturbation directions live in the identifiable subspace.

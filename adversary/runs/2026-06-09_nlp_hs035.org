* Formulation
#+begin_example
min  9 - 8 x1 - 6 x2 - 4 x3
     + 2 x1^2 + 2 x2^2 + x3^2 + 2 x1 x2 + 2 x1 x3
s.t. x1 + x2 + 2 x3 <= 3
     x1, x2, x3 >= 0
#+end_example

Pyomo model exported to AMPL .nl, giving both solvers identical EXACT

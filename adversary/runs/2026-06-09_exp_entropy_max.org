#+TITLE: Adversary cross-check — exp cone: maximum-entropy distribution on the simplex
#+DATE: 2026-06-09

* Problem properties
- FAMILY: exp (exponential cone)
- CLASS: entropy maximization
- SOURCE: Boyd & Vandenberghe, /Convex Optimization/, Sec. 3.5 / max-entropy
  example. Maximizing H(p) = -sum_i p_i log p_i subject to ONLY the
  normalization sum_i p_i = 1 yields the uniform distribution, H = log(n).
  Exact closed form; no numerical reference needed.
- KNOWN_OPTIMAL: log(n). For n = 5: log(5) = 1.6094379124341003,
  with p* = (1/5, ..., 1/5).
- N_VARIABLES (pounce): 2n = 10 (p_0..p_4 and epigraph z_0..z_4).
- CONE LAYOUT: n = 5 exp cones (3 rows each, 15 G rows) + one equality row.

* Formulation
Maximize sum_i z_i (i.e. minimize -sum_i z_i) with the per-coordinate
exp-cone relation z_i <= -p_i log p_i encoded as the triple

    (x = z_i, y = p_i, z = 1) in Kexp,

since Kexp = {(x,y,z): y*exp(x/y) <= z, y>0} gives
p_i*exp(z_i/p_i) <= 1  <=>  log p_i + z_i/p_i <= 0  <=>  z_i <= -p_i log p_i.
The slack ordering is s = h - G x = (z_i, p_i, 1). Normalization sum_i p_i = 1
goes in A,b. Reported entropy = -res.obj.

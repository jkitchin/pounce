* Problem

  minimize   Tr(C X)
  subject to X >= 0   (3x3 PSD)
             Tr(X) = 1

with

  C = [[ 2, -1,  0],
       [-1,  2, -1],
       [ 0, -1,  2]]   (tridiagonal Toeplitz / path-graph stiffness).

** Known optimum (closed form)

The Rayleigh-Ritz / Ky Fan (k=1) variational identity gives

  lambda_min(C) = min { Tr(C X) : X >= 0, Tr(X) = 1 },

with optimizer X* = v v^T, v the unit eigenvector for lambda_min (a rank-1
density matrix). Eigenvalues of C are {2 - sqrt(2), 2, 2 + sqrt(2)}, so

  KNOWN_OPTIMAL = 2 - sqrt(2) = 0.5857864376269050.

SOURCE: Vandenberghe & Boyd, "Semidefinite Programming", SIAM Review 38(1),
1996, sec. 2 (spectrahedron / trace-normalized PSD set); standard Rayleigh-Ritz.
